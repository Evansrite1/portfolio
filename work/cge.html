The problem

An electrical code consulting firm needed a professional web presence that did more than describe the service. Every visitor who was ready to talk needed a direct, frictionless path to booking a call, and the team needed to know immediately when someone did.

What I built

  • A fast, single-file static site with no build step and no framework overhead, cheap to host, quick to load.
  • Every "book a call" action routes straight into the firm's real Cal.com scheduling link, so a visitor picks a slot without leaving the flow.
  • A Telegram bot integration that notifies the team the moment a lead engages, so no enquiry sits unanswered.
  • Copy and structure built around what an electrical code consulting client actually needs to hear before they'll book a call.

Why it matters

The site turns interest into a booked call automatically, instead of leaving that step to a manual follow-up email. The client gets an instant notification the moment someone is ready to talk.
