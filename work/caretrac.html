The problem

Caregiving teams coordinate a lot of moving parts: who is on shift, what tasks need doing, and a daily log of what actually happened. Without a shared system, that information lives in scattered notebooks, memory and group chats, which makes handoffs between shifts risky and hard to audit.

What I built

  • A FastAPI backend with a dedicated scheduler service, so recurring tasks and shift logic run reliably in the background.
  • A React frontend for the day to day work: task names, daily log entries, and status at a glance.
  • A clean design system, dedicated typography and color rules, built for a caregiving team's real workflow rather than a generic admin panel.
  • A Railway plus Vercel deployment split, backend and scheduler on Railway, frontend on Vercel, kept independent of any third-party no-code platform.

Why it matters

Shift handoffs stop depending on memory. Every task and daily log entry lives in one system the whole team can see, so nothing gets lost between shifts.
