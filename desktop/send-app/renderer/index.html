What would you like to do?

Both computers need File Share installed, and both must be on the same Wi-Fi.

    Connect to Wi-Fi

    Both computers must be on the same Wi-Fi network, or plugged into the same router. A Guest network usually does not work.

              Save to

              Files go straight between the two computers over your Wi-Fi. Each file is checked on arrival. The connection is not encrypted, so use it on a network you trust.
