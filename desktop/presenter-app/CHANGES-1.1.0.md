# Presenter 1.1.0 (Nov 24 2026)

Built from Evans's list. The web parts (library, scripture, media) reach everyone as soon as the site is pushed. The app parts (no menu bar, update prompt, screen chooser, videos played from their folder) need this release.

## Done
- Songs: pen icon edits, double tap a song to add it to the service (not live), double tap it in the service to show it. Songs use the logo or plain black until a Song background is chosen. "Show only the title" option for songs the media team projects. Starter hymns button (14 public domain hymns).
- Scripture: type words and matching verses drop down under the box. Tab moves John, 3, 16. Book, chapter and verse columns. Import Bible button for licensed versions (txt with one verse per line, or json). Versions bar holds up to 12.
- Listen to the message: Whisper runs on the computer, finds verses the speaker names ("John 3:16", "Psalm one hundred and nineteen") and verses read aloud. Works offline once the speech files are saved (the app saves them the first time it is open online).
- Media: plus opens the file picker straight away, any photo, video or PDF type the app can decode, single click shows details and Add to service, double click shows it live and adds it to the service, keeps its own shape unless "Expand to fill" is pressed. In the desktop app videos play from the folder they are in (nothing copied).
- Phone: two at most, round dotted code only, no link.
- Screens: pick the screen for the show inside the app (TV screen button).
- No menu bar. Black by default with a black or light switch.
- Update prompt: asks when online and a newer version exists. Skip allowed twice, the third time there is only Update. Windows installs by itself, an unsigned Mac opens the download page.

## Not possible or not done
- NIV, NKJV, MSG, Amplified and TPT are copyrighted. No free copy exists. Import your own licensed copy, or get permission from the publishers.
- A full free database of Nigerian church songs does not exist (most are under copyright). Churches import their own songs.
- AVI and other formats Chromium cannot decode will not play. MP4, MOV, MKV and WEBM do.
