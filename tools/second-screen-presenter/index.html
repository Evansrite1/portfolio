Windows and Mac. No account. Nothing is uploaded.

Download for Windows
  1. Open the downloaded zip and press Extract all.
  2. Open the new folder and double-click Presenter Setup.
  3. If Windows says it protected your PC, press More info, then Run anyway.
  4. Press Install Presenter. It takes one to two minutes and opens by itself.
Download for Mac, Apple chip
  1. Open the downloaded zip. It holds the installer and a Read me first file with these steps.
  2. Open the .dmg and drag Presenter into Applications.
  3. Open Terminal (Command and Space, type Terminal), paste this line and press Enter:xattr -cr "/Applications/Presenter by Evans Large.app"
  4. Open Presenter. If the Mac still warns you, open System Settings, Privacy and Security and press Open Anyway.

M1, M2, M3 or M4 Mac? This one. Not sure? Apple menu, About This Mac.

Internet. You do not need it to run Presenter. When the internet is on, the app checks for updates by itself and shows an Update now button, and you can add more Bible versions. With no internet, everything else works as normal.

Everything it does

  • Songs libraryYour songs, searched as you type. Double tap to show.
