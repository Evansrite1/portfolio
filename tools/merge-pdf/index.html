Merge PDF files

Combine several PDFs into one. Reorder the files, use only the pages you want from each, and download the result. Everything runs in your browser, so your files are never uploaded.

Drop PDF files here or choose files

Add two or more PDFs. Password protected files must be unlocked first.

    To use only some pages of a file, type them in its Pages box, for example 1-3, 5. Leave it empty to use every page.

    How to merge PDF files

    1. Add your PDFs. Drop two or more files on the box, or choose them. Each file shows its page count and a picture of its first page.
    2. Set the order. Drag files up or down, or use the arrow buttons. The merged PDF follows the list from top to bottom.
    3. Pick pages (optional). Type a page range such as 1-3, 5 in the Pages box of any file to use only those pages.
    4. Merge and download. Press Merge PDFs, check the page count and save the new file.

    Merge only the pages you need

    You do not have to merge whole files. Type 1-3, 5 to take pages 1, 2, 3 and 5, or 4- to take everything from page 4 to the end. Pages are merged in the order you type them, so 5, 1-2 puts page 5 first. Add the same file twice if you want to use different parts of it in different places.

    Tips and common uses

    • Combine a cover letter, CV and certificates into one application file.
    • Join invoices or statements from several months into a single document.
    • If a file says it is password protected, open it in your PDF viewer, save a copy without the password, and add that copy.
    • Pages keep their original size and rotation. Bookmarks and interactive form fields from the source files may not carry over.

    Frequently asked questions

    Is this PDF merger free?

    Yes. There is no sign-up, no watermark and no limit on how many PDFs you merge.

    Are my PDFs uploaded to a server?

    No. The files are merged inside your browser on your own device, so they never leave it. That makes it safe for private documents.

    How do I change the order of the files?

    Drag a file up or down in the list, or press the up and down arrows on it. The merged PDF follows the list from top to bottom.

    Can I merge only some pages of a file?

    Yes. Type a range such as 1-3, 5 in the Pages box of that file. Leave the box empty to use every page.

    Why does it say my PDF is password protected?

    The file is encrypted, and this tool cannot read pages without the password. Open it in a PDF viewer, save or print a copy without the password, and add that copy instead.

    What happens with a damaged PDF?

    The tool tells you which file could not be read and does not add it. The other files are not affected, so you can carry on without it.

    Is there a limit on file size?

    There is no fixed limit. Very large PDFs depend on your device memory, because the work happens on your own computer. If a merge fails, try fewer files at a time.
