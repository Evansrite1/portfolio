How to create a QR code

  1. Choose what the code should do. Pick a link, text, email, phone number, SMS, WhatsApp chat, WiFi network, contact card or map location.
  2. Type or paste your details. The QR code updates as you type, so you can see it straight away.
  3. Customize it. Change the colors and the shape, set the error correction level, or add your logo in the middle.
  4. Download and test. Save a PNG for screens and documents or an SVG for printing, then scan it with your phone before you share it.

Tips for a QR code that scans every time

  • Keep strong contrast. Dark code on a light background scans best. Avoid light code on a dark background.
  • Leave the quiet zone. The empty border around the code should stay at 4 modules wide. Do not crop it.
  • Print it big enough. Aim for at least 2 by 2 cm (about 0.8 inch). As a rule, the scanning distance can be about ten times the width of the code.
  • Keep the content short. Shorter links make simpler codes that scan faster and from further away.
  • Use High error correction with a logo. It lets the code survive the logo covering part of the middle. This tool sets it for you, removes the logo background and fits it to the center automatically.
  • Always test. Scan the finished code with an iPhone and an Android phone before you print a thousand flyers.

Frequently asked questions

Is this QR code generator really free?

Yes. There is no sign-up, no watermark, no limit on how many codes you make and no payment for downloads.

Do these QR codes expire?

No. The data is stored inside the code, so it never expires. A code that points to a website keeps working as long as that website address does.

What is the difference between static and dynamic QR codes?

A static code holds the information directly and cannot be edited later. A dynamic code points to a short link on a service that can change where it goes and count scans, and those services usually need a paid account. This tool makes static codes.

What size should I print a QR code?

At least 2 by 2 cm (about 0.8 inch). For posters and signs, make it larger so people can scan from a distance. Use the SVG download for large prints because it stays sharp at any size.

Which error correction level should I choose?

Medium is fine for most uses. High lets a code still scan when up to 30% is damaged or covered, which is why it is used when you add a logo. Higher levels make the pattern denser.

Can I add my logo to the QR code?

Yes. Choose a logo image in the design options. Keep it small and test the result with your phone. The tool raises error correction to High automatically.

Should I download PNG or SVG?

Use PNG for websites, documents and social media. Use SVG for printing, because it is a vector file that scales to any size without blur.

Is my data private?

Yes. The code is generated in your browser. Nothing you type is uploaded or stored by this site.

Can I track how many people scan my code?

Not with a static code. If you need scan counts, point the code to a link that you control, add tracking parameters to it, and read the results in your analytics tool.
