WiFi QR code generator

Let guests join your WiFi by scanning a code instead of typing a long password. Enter your network name and password, then print the code or download it. Your password never leaves your browser.

Customize the design

Any image works. The background is removed, the logo is trimmed and fitted to the center, and error correction is set to High so the code still scans.

How to make a WiFi QR code

  1. Enter your network name exactly as it appears on your devices, including capital letters.
  2. Choose the security type. WPA covers WPA, WPA2 and WPA3 networks, which is almost every router today.
  3. Type the password. Use the Show password box to check it.
  4. Print or download the code and put it where guests can see it.

How guests scan it

iPhone and iPad: open the Camera app, point it at the code and tap the banner that appears. Android: open the camera or Google Lens, point it at the code and tap to join. Most recent phones need no extra app.

Where to put it

Cafes, restaurants, offices, waiting rooms, rental apartments, guest rooms and event venues. Frame the printed code near the entrance or on the table.

Remember that anyone who can scan the code can join the network, so treat it like the password itself. If you share a guest network, give guests that one rather than your main network.

Frequently asked questions

Is it safe to make a WiFi QR code here?

Yes. The code is created in your browser and your network name and password are not uploaded or stored by this site.

Which security type should I choose?

Choose WPA for WPA, WPA2 and WPA3 networks. Choose WEP only for very old routers. Choose No password for open networks.

Why does the code not connect?

Check that the network name matches exactly, including capitals and spaces, and that the password is correct. If the network is hidden, tick the hidden network box.

Does the QR code stop working if I change the password?

Yes. The password is stored inside the code. If you change it, make a new code and replace the printed one.

Can I print the WiFi code?

Yes. Use the Print button for a clean page with just the code and the network name, or download the SVG for large prints.
