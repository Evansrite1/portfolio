How to make a WhatsApp link

  1. Choose your country and type the number. Type it as you normally dial it. The tool removes spaces, dashes, a leading 0 or 00 and a plus sign, and adds the country code.
  2. Write the message (optional). Pick a template for an order, booking, support request or quote, or write your own. The preview shows what the person will see in the chat box.
  3. Copy the link. Use Open to test to check it opens your chat, then paste the link into your bio, website, email signature or ad.
  4. Use the QR code. Download the PNG and put it on a flyer, receipt, shop window or menu so people can scan and start a chat.

What a wa.me link is

A wa.me link looks like https://wa.me/2347035940200?text=Hello. The number is written with the country code and digits only, with no plus sign, no spaces and no leading 0. When someone taps it, WhatsApp opens a chat with that number and puts the text in the message box. They still have to press send.

The text is URL encoded, which means characters such as spaces, new lines, ampersands and accented letters are replaced with codes like %20 and %0A. This is what lets a long message with line breaks survive inside a link, and the tool does it for you.

wa.me links and the WhatsApp Business API

A wa.me link is a free shortcut that opens a chat in the WhatsApp or WhatsApp Business app. It does not need an account with Meta, an approval or a developer. The WhatsApp Business API is a separate paid service for companies that send messages from software, run several agents on one number or send approved template messages. A wa.me link can send people to a number that uses either one.

Frequently asked questions

How do I create a WhatsApp link?

Choose your country, type your number, add a message if you want one and copy the link. It has the form wa.me followed by your number with the country code.

Do I put a plus sign or a zero in the number?

No. In a wa.me link the number has the country code and digits only. You can type it any way you like and the tool removes the plus sign, spaces, dashes and a leading 0 or 00.

Why is my message full of percent signs in the link?

The message is URL encoded so spaces, line breaks, ampersands and non-English letters work inside a link. WhatsApp turns the codes back into your text.

Is a wa.me link the same as the WhatsApp Business API?

No. A wa.me link just opens a chat in the app and needs no approval. The Business API is a separate paid service for sending messages from software.

Can I make a QR code for my WhatsApp link?

Yes. The QR code on this page contains the same link. Download the PNG and print it. When someone scans it, WhatsApp opens your chat with the message ready.

Does the link work on the desktop and on phones?

Yes. On a phone it opens the WhatsApp app. On a computer it opens WhatsApp Web or the desktop app if the person has it.

Is my number sent to your server?

No. The link and QR code are made in your browser, and nothing is uploaded.
