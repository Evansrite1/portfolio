How to make a WhatsApp QR code

  1. Enter your number with the country code. Digits only, no plus sign and no leading zero. For example 2347012345678 for a Nigerian number.
  2. Add a message (optional). It appears already typed in the chat, for example "Hello, I would like to place an order".
  3. Copy the link or download the code. Use the link in bios and buttons, and the QR code on printed material.

Where to use it

  • Shop windows, menus and receipts, so customers can order or ask questions.
  • Business cards, flyers and posters.
  • Instagram, TikTok and website buttons, using the link.
  • Event registration desks and product packaging.

Country codes

Nigeria 234, Ghana 233, Kenya 254, South Africa 27, United Kingdom 44, United States and Canada 1, United Arab Emirates 971, Kuwait 965. Remove the leading 0 from the local number before adding the code.

Frequently asked questions

Do I need WhatsApp Business?

No. The link and QR code work with a normal WhatsApp account as well as WhatsApp Business.

Will people see my phone number?

Yes. The chat opens with your number, so only use a number you are happy to share.

Can customers message me without saving my number?

Yes. Scanning the code or tapping the link opens a chat directly.

Why does my link not open the right chat?

The number must include the country code and have no plus sign, spaces or leading zero. The tool shows a warning if the number starts with 0.

Does the code expire?

No. It is a static code that holds the link. It works for as long as the number is active on WhatsApp.
